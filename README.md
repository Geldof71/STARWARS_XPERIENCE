# Star Wars Xperience VR

VR rondleiding van de Star Wars Xperience in een grijs model van de RAI Amsterdam.
SMP blok 6, Hogeschool van Amsterdam. Elvin Spooren, Stan Geldof en Coen Geldof.

## Openen
Open de GitHub Pages link in de browser van een VR bril (Quest of Pico) en kies "Enter VR".
Op een laptop kun je rondlopen met muis en toetsenbord, of VR nabootsen met de Chrome extensie Immersive Web Emulator.

## Bron
Hallen en gangen zijn overgetrokken van de RAI hallenplattegrond (2025), ongeveer 0,5 meter per pixel.
Plafondhoogtes en deuren zijn aannames.
